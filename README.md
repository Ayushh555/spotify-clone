# Spotify Clone 🎵

A simple Spotify-inspired music player interface built using **HTML and CSS**.  
This project focuses on recreating the look and feel of Spotify with a clean and responsive design.

## Features

- 🎧 Spotify-inspired UI
- 📱 Responsive layout
- 🎵 Music player interface
- 📂 Sidebar navigation
- 🎨 Clean and modern design

## Tech Stack

- HTML5
- CSS3

## Preview

A frontend-only project created for learning and practicing HTML & CSS.
